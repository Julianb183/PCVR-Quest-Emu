# Windows XP 1GB Simulator for Roku

This is a clean-room Roku SceneGraph app that presents an original desktop-style interface inspired by classic Windows layouts.

It is **not Windows XP**, does not run Windows programs, and does not include Microsoft files or firmware. The `1024 MB` label is simulated UI state; Roku apps cannot allocate a configurable 1 GB virtual machine.

## Controls

- Press **OK** to open the simulated Start menu message.
- Press **Back** to return to the desktop message.

## Sideloading

Enable Developer Mode on the Roku, package this folder as a Roku ZIP using the official Roku development tools, and upload it through the Roku developer installer.
